# 🚀 Quick Start - OpenClaw + Jarvis Autonomy

## Installation en 3 commandes

```bash
git clone https://github.com/votre-repo/openclaw.git
cd openclaw
pnpm install
```

**C'est tout !** L'autonomie Jarvis est installée et configurée automatiquement.

---

## Démarrage

```bash
pnpm dev
```

Puis ouvrir : http://localhost:3000/autonomy

---

## Vérification

```bash
pnpm jarvis:doctor
```

Doit afficher : `✅ 9/9 vérifications OK`

---

## Commandes utiles

```bash
pnpm dev                    # Démarrer
```
